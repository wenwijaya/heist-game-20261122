Midnight Vault — a top-down stealth heist game. Cross three museum halls, dodge guard vision cones and sweeping security cameras, grab the diamond, and slip out the exit before the alarm hits 100. Three levels, three lives, score for loot plus time and stealth bonuses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, Space to start, P to pause, M to mute.
